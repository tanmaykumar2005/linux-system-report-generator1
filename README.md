# Linux System Report Generator

## Overview
A simple Bash command-line tool that collects basic
information about a Linux computer and saves it in
a readable text report.

## Features
- Displays the hostname
- Displays the kernel version
- Shows disk usage
- Shows memory usage
- Lists the top running processes by CPU usage

## Requirements
- Linux operating system
- Bash shell
- Standard Linux utilities

## How to Run
1. Open a terminal in the project directory.
2. Make the script executable:

   chmod +x system_report.sh

3. Run the script:

   ./system_report.sh

4. The report will be saved as system-report.txt.

## Project Files
- system_report.sh - Main Bash script
- system-report.txt - Generated system report
- README.md - Project documentation
